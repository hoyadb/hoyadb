The React Native native bootstrap is source-checked, not compiled or executed; the report states those limits. Each example uses assertions, not printed output alone. Control the host, keep the database real

Inject IDs, UTC and monotonic clocks separately. Testing packages supply retained real memory storage, fake transport and manual timing capabilities. A retained store supports close/reopen and authored migration tests; replacing it with a fresh store cannot prove persistence. Never use a fake database to claim a core behavior passed.

Test the difficult boundaries

Check rollback on failed batches, wrong-key open, duplicate and conflicting receipts, callback cancellation, stale pull, full-result frame limits and close/reset invalidation. Validate both data and queue state after a failure. A successful import, typecheck or build is not runtime proof on another platform.

The shared conformance suite supplies additional recovery examples and the SDK observation tests exercise host delivery.
