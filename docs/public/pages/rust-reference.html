Adapter capability hierarchy

Storage is the low-level row store; transactional and typed traits add atomic mutations and checked schema/query behavior. SchemaStorage adds model lifecycle, ObservationStorage adds projected reads and SyncStorage adds durable queue plans and ownership reporting. Follow the trait reference when implementing a custom engine; a capability claim is a behavioral obligation, not an optimization switch.
