Adapter
A storage implementation satisfying the selected core traits.
Owner
The open Database, ReactiveDatabase or CommandDatabase that enforces its model and lifecycle.
Command
A named business action with arguments, captured context and staged local effects.
Scope
The isolated local read/write view used before command finish.
Envelope
The canonical frozen command/entity payload used for dispatch and byte-identical retry.
Receipt
Delivery acknowledgement, optionally carrying an authoritative outcome.
Reconciliation
The checked local plan that applies or confirms an authoritative result.
Entity
A configured row-level sync shape with per-field comparison state.
Tombstone
Retained entity deletion comparison metadata.
Checkpoint
An opaque backend position advanced only with a committed pull page.
Subscription
A registration token routing owned observation or sync events.
Local reference
A reference to a locally created command identity whose producer/mapping is tracked by core.
Guard
An exact expected before-image protecting a correction against concurrent changes.
