Keep ownership explicit

An open owner does not expose mutable raw storage. Consume it with into_storage when you need to reopen with a new schema or retain a memory adapter. Do not create a competing connection behind an owner. Native SQLite has store ownership checks; custom adapters must report their ownership capability truthfully. Unproven stores retain conservative validation and comparison paths.

Local commit and delivery are separate

Core owns data and queue rules. The host owns an executor, clocks, network requests, callbacks and timers. Notification publishing after a successful commit is not a way to roll back that commit. A dropped asynchronous operation must be interpreted at its actual cancellation boundary; never infer failure from a missing callback alone.

Current and planned work

Repeated-edit confirmation, row-causal dispatch and guarded corrections have implementation in the checked source. Change-proportional sync ledger work (R9), stable metadata format conversion and stop/discard policy remain active design/remediation work. This site does not advertise their planned APIs or performance guarantees as available.
