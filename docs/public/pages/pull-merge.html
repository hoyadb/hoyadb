Offer custom merges without granting authority

The example exercises the passive session's Ready/commit path with an empty page. For an offered table, merge_prepare can return Offer. Read its owned merge_input, await your application hook, submit the proposal with merge_reply and continue until Ready. Only merge_commit applies the staged page. Abort disposes the session.

A proposal is a row or absence constrained by core validation; hooks cannot fabricate new comparison metadata or bypass tombstones. SDK hooks receive immutable owned input. Busy can be retried with the retained proposal; StalePull means the captured page can no longer be committed and must be fetched again from the unchanged checkpoint.

Reset is explicit

ResetMode::PreserveRecovery is the conservative choice. DiscardRecovery is a separate destructive recovery decision, not the planned per-command Discarded state. Reset invalidates tickets and subscriptions. This documentation executes no reset against a persistent user store.
