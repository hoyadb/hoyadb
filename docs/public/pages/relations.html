To-one and has-many

The example creates an author and a note, navigates in both directions and filters by the author's name. The to-one declaration creates the typed author_id foreign key. A has-many relation points back at that same field.

Many-to-many

ManyToMany names a through table and its source/target to-one relation names. Model link payload as columns on that through table. link returns an existing identical membership or inserts one; conflicting existing payload is rejected. unlink removes matching memberships. A command scope offers scoped versions so relationship changes can join the optimistic transaction.

References are typed IDs, not automatic existence checks. Deleting a source does not establish a cascade policy. Use explicit command logic when business rules require consistent removals. For configured entity tables use the entity-aware wrappers exposed by your SDK.
