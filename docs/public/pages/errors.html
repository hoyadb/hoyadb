Match kinds, not diagnostic prose

Rust exposes StorageError and CommandError variants. SDK failures expose a static kind. Messages are diagnostic and can change; do not use message text to decide retries or expose backend details to end users.

The examples use run, schema, fields and owner from the example support module. run drives this memory fixture; applications with suspending adapters use their async executor. The examples use unwrap() to stop on unexpected failures; an application should handle the typed errors.

Callbacks after commit

A callback failure does not reverse a committed write. Supported SDK background sinks report redacted source/kind/token metadata and contain sink failures. Android has a recorded source gap for that contract; do not assume reporting parity. See platform caveats.
