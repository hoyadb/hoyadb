Rust

The workspace packages are hoyadb-core, hoyadb-storage-memory, hoyadb-storage-sqlite and hoyadb-bindings. Their manifests mark them unpublished. Add path dependencies to a local checkout instead of inventing a crates.io version. The executable documentation manifest is a complete working dependency example.

rust-toolchain.toml pins Rust 1.98.1, rustfmt, clippy and the wasm32 target. The offline commands assume that exact toolchain and locked Cargo dependencies are already installed. Initial dependency provisioning is separate from the offline example run.

JavaScript and web

@hoyadb/client and @hoyadb/testing are private local packages. Build the ordinary WASM artifact with sh crates/hoyadb-web/build.sh; the script requires the installed wasm-bindgen 0.2.129 CLI and a compatible WASM C compiler. It uses locked offline Cargo resolution. Then node tools/javascript/scripts/build.mjs creates local package output. See the package instructions for local tarball consumer verification.

Native hosts

Swift uses a local SwiftPM package and a generated XCFramework. React Native wraps the same portable JavaScript host over a native channel. Android has Kotlin source and packaging recipes; execution remains held. See platform setup and limits. The presence of a wrapper or a successful host build does not prove a device target works.

For compiled local examples, see Swift and C. Their documentation runner stages fresh native artifacts under ignored target/documentation-languages/ and preserves packaged artifacts. TypeScript uses the installed compiler; no compiler is downloaded.

Rebuild this documentation

Run python3 docs/public/verify.py, then python3 docs/public/build.py. Open docs/public/dist/index.html directly. These Python scripts use only the standard library. The build also generates Rust API reference with Cargo. No static-site package, CDN or documentation server is required.
