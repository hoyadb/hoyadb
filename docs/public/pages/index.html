One local model, an explicit sync boundary

Your application owns its schema, identity, backend transport and conflict decisions. hoyadb validates local data, commits changes through the selected adapter and exposes owned query results. The command owner adds optimistic scopes, durable retries and reconciliation. Network access is supplied by your application.

Choose a reading path

  1. Prepare the local packages and run the quickstart.
  2. Learn schemas and values, queries and observations.
  3. Add commands or entity sync when a backend is ready.
  4. Use protected persistence and deterministic tests before integrating a platform host.
