# REQ-0048: Public contributor checkout

The source checkout SHALL contain the instructions and tooling needed to build,
test and validate the documented contribution workflow without access to a private
governance repository. Package names, public APIs and required quality checks SHALL
remain unchanged during the repository reorganization.

Origin: operator approval on 2026-10-30 of both the release-oriented folder
organization and separation of private maintainer governance from the public
contributor contract. This does not select a distribution license or authorize
publication, commits, deletion of existing work or rewriting Git history.
