# REQ-0047: Public developer documentation includes executable examples

The library SHALL provide offline-readable HTML documentation covering getting
started, concepts, practical guides and public API reference. Runnable examples
SHALL be included from checked-in source and executed against the real library.
Source reference for platforms whose execution remains held SHALL be identified
as source-only, with no claim of runtime verification. Documentation SHALL
identify its source version and distinguish implemented APIs from planned work.

Source: operator request on 2026-10-27 to create full HTML documentation, test all
examples, and use Claude for assistance with the work.
