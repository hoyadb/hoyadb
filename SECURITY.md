# Security reporting

The private vulnerability-reporting channel has not yet been configured. This
must be resolved before public launch; do not put keys, user data, exploit details
or other confidential material in a public issue while that channel is absent.

No supported release series or security-update schedule is declared yet. Current
packages are local and unpublished. See the [security integration guide](docs/guides/security-integration.md)
for implemented protections and their limits, and the [threat models](docs/design/security/)
for the design record.
